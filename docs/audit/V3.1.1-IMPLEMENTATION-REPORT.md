## 3. Changes implemented

- **Mode isolation** (`src/chat/session.ts`, `src/chat/persistence.ts`, `src/chat/attachmentContext.ts`, `src/chat/protocol.ts`, `src/chat/chatViewProvider.ts`, `media/chat.js`): per-mode drafts, per-mode replay, conversation restore carries mode, webview resets drafts on restore/clear; Ask replay drops agent-mode rows.
- **Agent lifecycle** (`src/agent/orchestrator.ts`, `src/chat/chatViewProvider.ts`): repository-remove-before-memory protocol; persistence failure surfaces to the user as an error and keeps in-memory session; reload cannot revive a deleted session; busy-session attempts give the cancel-first message.
- **Attachment retry** (`src/chat/chatViewProvider.ts`, `src/chat/protocol.ts`, `media/chat.js`): pending-failed-request tracking; identical `ChatMessage[]` resent without duplicating user message; attachments retained across provider failure.
- **Read-only inspection** (`src/workspace/inspectionReport.ts`, `src/chat/chatViewProvider.ts`): deterministic verb classification; zero-provider-call, zero-write, zero-command local report with indexed totals, manifest outcomes, and Git status when available; no plan, no approval pipeline.
- **Quality** (`src/languages/registry.ts`, Ask/Explain guidance): Python `__all__`/`__main__` guard, Java interface default/static/private methods.
- **Rendering** (`media/chat.js`): HTML code-block language normalizer strips Copy-suffixed aliases.
- **Deletion lifecycle** (`test/unit/agentDeleteLifecycle.test.ts`): store-first deletion, in-memory preservation on failure.

## 6. Security verification

v3.1.1 inherits v3.1.0's approval gates and adds no path that bypasses them. The new Read-only Inspection flow is provider-call-free and file-write-free by construction (no `changes.prepare`/`apply`, no `runCommand`). Transcript replay is mode-scoped to prevent one mode leaking its prompt into another. Inline Python/Java guidance improves baseline Ask/Explain accuracy without expanding capability. No existing security regression tests were modified or skipped.
