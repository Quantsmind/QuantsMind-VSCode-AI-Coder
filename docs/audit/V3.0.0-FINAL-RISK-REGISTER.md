## Accepted risks (explicit, disclosed)

- **QM-GA-034** — `allowInsecureLocalhost` defaults to `true` (loopback plain-HTTP for local
  model servers; remote HTTP always rejected; per-request warn log; opt-out `quantsmind.provider.allowInsecureLocalhost: false`).
  Distribution-level default; accepted with full disclosure; publication-time owner decision to flip it.
- **QM-GA-043** — manifest `preview: true` retained and pinned by two integration tests; the build is not published;
  flip at publication time by the publication owner. Not a security control and not weakened by this release.

## Documented product limitations (accepted as such — not hidden, not misrepresented)

- Only one workspace root is indexed (marker-scored selection; user-visible notice at activation since `181b136`).
- Language intelligence is lexical/inventory, not compiler-grade; unsupported constructs are reported as unsupported, never faked.
- Remote/live provider calls were never executed in this environment; GitHub integration is fixture-verified only.
- Web and virtual workspaces are not supported by product design (`capabilities.virtualWorkspaces: false`).
- Restricted Mode keeps a chat read-only surface only; all workspace access is denied without trust.
- Live Pollinations qualification remains pending (offline environment; no credentials consumed).
